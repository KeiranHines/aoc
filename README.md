# AOC

## Description
Repo for Advent of Code challenges. One branch for each year. 

This year is 2025, written in Rust.

## Running days
place a text file for your input in inputs/dayX.txt where X is the day. E.g. inputs/day1.txt
### running challenge 
`cargo run --bin dayX` e.g. `cargo run --bin day1`
### running tests 
`cargo test --bin dayX` e.g. `cargo test --bin day1`
or 
`bacon test -- --bin dayX` required bacon `cargo install --locked bacon`
